# VaulType Website

The official website for [VaulType](https://github.com/vaultype/vaultype) — a privacy-first, macOS-native voice-to-text application.

**Live:** [vaultype.app](https://vaultype.app)

## Stack

- [Astro 5](https://astro.build/) + [Starlight](https://starlight.astro.build/) for documentation
- [Tailwind CSS v4](https://tailwindcss.com/)
- Static site hosted on a VPS with Nginx

## Development

```bash
# Requires Node 20+
npm install
npm run dev
```

Open [localhost:4322](http://localhost:4322).

## Build

```bash
npm run build
```

Output goes to `dist/`.
